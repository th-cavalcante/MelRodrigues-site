## 🧪 Teste em Celular

### Versão Virtual (F12)
1. Abra o site em `http://localhost:3000`
2. Pressione `F12` no navegador
3. Clique no ícone de celular
4. Veja funcionando perfeitamente!

### Celular Real
Se quiser testar em outro celular/tablet na mesma rede:
1. Pegue seu IP local (execute no CMD: `ipconfig`)
2. Procure por "IPv4 Address": `192.168.x.x`
3. No outro dispositivo, acesse: `http://192.168.x.x:3000`

## ⚙️ Personalizações Fáceis

### Mudar WhatsApp
Arquivo: `src/components/Navbar.jsx` (procure por `wa.me`)

Substitua `5511987654321` pelo seu número:
- Exemplo: (11) 98765-4321 → `5511987654321`

### Mudar Cores
Arquivo: `src/styles/globals.css` (procure por `:root`)

```css
--primary-color: #d4af37;  /* Mude essa cor */
```

### Mudar Contato
Arquivo: `src/components/Footer.jsx`

- Endereço
- Email
- Horário
- Links sociais

Para mais personalizações, veja **CUSTOMIZACOES.md**

## 🤔 Troubleshooting Rápido

### "npm não é reconhecido"
→ Instale Node.js: https://nodejs.org/

### Porta 3000 em uso
```bash
npm start -- --port 3001
```

### Aplicação em branco
→ Pressione `F12`, veja se há erros no console

### Quer parar o servidor?
→ Pressione `Ctrl + C` no terminal
