# MR Laser Concept - Website

Website profissional da **MR Laser Concept**, uma marca especializada em:
- 💇‍♀️ Clínica de Estética - Depilação a Laser Personalizada com Tecnologia Hakon 4D
- 🎓 Cursos Profissionalizantes - Capacitação em Depilação a Laser
- 🔧 Locação Hakon 4D - Aluguel de Equipamento para Esteticistas

## 🛠️ Stack Tecnológico

- **Frontend**: React 18.2.0
- **Roteamento**: React Router DOM 6.14.0
- **Estilos**: CSS3 moderno com Pré-processamento
- **Build Tool**: Create React App 5.0.1

## 📋 Requisitos

- Node.js 14+ 
- npm ou yarn

## 🚀 Como Executar o Projeto Localmente

### 1. Clone ou extraia o projeto

```bash
cd "c:\Meus Projetos\Site-mrlaser"
```

### 2. Instale as dependências

```bash
npm install
```

### 3. Inicie o servidor de desenvolvimento

```bash
npm start
```

Isso abrirá automaticamente a aplicação em `http://localhost:3000` no seu navegador.
